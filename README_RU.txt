Page Inspector 3.1 — установка и ограничения

1. Распакуйте ZIP в отдельную папку.
2. Откройте chrome://extensions (или edge://extensions), включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json.
4. Обновите исследуемую веб-страницу и откройте расширение.
5. Нажмите «Максимальный снимок» (всё со значениями) или «Подробный снимок без секретов».
   Не закрывайте окно до завершения. Для долгих снимков нажмите «Открыть в отдельном окне» —
   такое окно не закрывается при клике мимо, как обычный попап.

МАКСИМАЛЬНЫЙ СНИМОК (3.1)
Файл inspector_full_*.json, для каждого доступного фрейма:
- cookie через chrome.cookies: все атрибуты, включая HttpOnly, Secure, SameSite, срок, partitioned
  (CHIPS) и cookie других путей и поддоменов сайта; плюс сырое document.cookie;
- localStorage и sessionStorage целиком (ключи и значения);
- IndexedDB: схема (keyPath, индексы) и записи; бинарные данные — base64, Map/Set/Date с пометками;
- Cache Storage: URL, заголовки ответов и текстовые тела; OPFS: файлы (мелкие — с содержимым);
- service workers, оценка квоты хранилища, persisted;
- DOM: плоское дерево с геометрией, стилями, ::before/::after, ОТКРЫТЫЙ И ЗАКРЫТЫЙ Shadow DOM,
  комментарии, тексты скриптов, текущие значения полей (в т.ч. пароли), выбранные option, файлы
  в input[type=file] (имена/размеры), состояние медиа, canvas как PNG, фокус и выделение;
- полный HTML фрейма вместе с shadow DOM;
- CSS всех таблиц, включая @import и adoptedStyleSheets; загруженные шрифты;
- performance: navigation, resources, paint, LCP, layout-shift, long tasks, память JS;
- глобальные переменные страницы (MAIN-мир): __NEXT_DATA__, состояние Redux/Apollo и т.п.;
- окружение: navigator, userAgentData, экран, часовой пояс, media-запросы, разрешения;
- полное дерево фреймов вкладки и список фреймов, куда внедриться не удалось.
Дополнительно (флажки):
- MHTML: страница целиком с картинками, стилями и фреймами (открывается в Chrome офлайн);
- DevTools: тела всех загруженных ресурсов (JS, CSS, картинки, XHR/fetch, если они в кэше
  вкладки), включая кросс-доменные iframe. Во время работы Chrome показывает плашку
  «Расширение отлаживает этот браузер» — это нормально, она исчезнет после выгрузки.

ВНИМАНИЕ: максимальный снимок содержит значения cookie сессии, токены и пароли из полей.
Кто получит файл — получит доступ к вашим аккаунтам на этом сайте. Не публикуйте и не
пересылайте его. Данные никуда не отправляются, только сохраняются в папку загрузок.

Ограничения максимального режима: каждый фрейм — до 200000 узлов, 30 с обхода DOM, 30 млн
символов текста и HTML, 10 млн CSS, 30 млн символов IndexedDB (до 20000 записей на хранилище),
5000 записей Cache Storage; DevTools — до 50 МБ на ресурс и 300 МБ всего. Превышение
отмечается в coverage.issues. Тела сетевых ответов, которых нет в кэше вкладки (например,
ответы POST), DevTools выдать не может. Геттеры глобальных объектов не вызываются.

ПОДРОБНЫЙ СНИМОК БЕЗ СЕКРЕТОВ (как в 3.0)

Сбор запускается только кнопкой; отправки на внешний сервер нет.
Новый режим: плоское дерево DOM со связями parent, открытые shadow roots,
содержимое template, геометрия, прокрутка, состояния контролов без значений,
медиа, таблицы стилей, доступные performance-ресурсы, имена ключей хранилищ,
имена доступных cookie, перечень IndexedDB-баз и Cache Storage без содержимого.
Ожидание: окно без DOM-мутаций 700 мс, максимум 4 с; не означает завершения сети.
Лимиты каждого фрейма: 50000 узлов, 20 млн символов текста, 15 с обхода DOM,
2 млн символов CSS и 20000 записей ресурсов. Ошибки и пропуски — в coverage.
Лимит времени DOM не является общим таймаутом всей операции.

Cookie и хранилища только читаются для метаданных, не изменяются и не удаляются.
Значения cookie, токены, пароли, значения полей и значения хранилищ не экспортируются новым режимом.
Это не резервная копия сессии и не автономная копия сайта. Ресурсы не скачиваются.
Имена ключей, текст страницы, CSS и URL могут содержать персональные данные:
маскирование не является гарантированной очисткой всех секретов.
Старые HTML/JSON-режимы сохранены для совместимости и могут содержать чувствительные данные.
Сохраненный HTML может содержать скрипты: не открывайте недоверенный экспорт как обычную страницу.
Служебные страницы браузера и часть фреймов недоступны расширениям.
Закрытый Shadow DOM и виртуализированный контент вне DOM не собираются.
Разрешения 3.1: добавлены cookies (полный список cookie), webNavigation (дерево фреймов),
pageCapture (MHTML) и debugger (тела ресурсов). Широкий доступ <all_urls> сохранён.

Проверено: node --check; максимальный режим прогнан в Chromium (headless) на тестовой странице
с HttpOnly-cookie, cookie другого пути, local/sessionStorage, IndexedDB с бинарными данными,
Cache Storage, закрытым Shadow DOM, canvas, введёнными значениями полей и кросс-доменным iframe.
На реальных сайтах вручную не проверялось.
