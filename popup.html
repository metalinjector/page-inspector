Selector probe

Готово.
Максимальный снимок содержит значения cookie (включая HttpOnly), хранилищ, IndexedDB и полей — по сути доступ к вашей сессии. Не передавайте файл посторонним.
Подробный режим не экспортирует секретные значения. Обычные HTML-снимки могут содержать личные данные и активные скрипты. Не публикуйте экспорт без проверки.
Обычный JSON включает: route, headings outline, карту [data-testid], ARIA landmarks, iframes, shadow-hosts, scroll-контейнеры, повторяющиеся группы карточек, активные табы (aria-selected/data-state), формы+inputs, CSS-переменные, og/twitter meta, ключи local/sessionStorage, focus/selection.
